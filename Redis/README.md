# CVSentry Redis Setup

Authenticated Redis instance for CVSentry, running inside a Docker container.

## Quick Start

### 1. Configure credentials

```bash
cp .env.example .env
# Edit .env and set REDIS_USERNAME and REDIS_PASSWORD
```

### 2. Start Redis

```bash
./setup.sh
```

The script will:
- Read credentials from `.env`
- Generate the `users.acl` ACL file
- Start the Redis container via Docker Compose

### 3. Connect

```
Host:     localhost  (or REDIS_HOST from .env)
Port:     6379       (or REDIS_PORT from .env)
Username: <REDIS_USERNAME>
Password: <REDIS_PASSWORD>
```

Python example:

```python
import redis
import os
from dotenv import load_dotenv

load_dotenv()

r = redis.Redis(
    host=os.getenv("REDIS_HOST", "localhost"),
    port=int(os.getenv("REDIS_PORT", 6379)),
    username=os.getenv("REDIS_USERNAME"),
    password=os.getenv("REDIS_PASSWORD"),
    decode_responses=True,
)

r.ping()  # Should return True
```

## File Reference

| File               | Purpose                                               |
|--------------------|-------------------------------------------------------|
| `.env`             | **Your** credentials (gitignored, never commit)       |
| `.env.example`     | Template showing required variables                   |
| `docker-compose.yml` | Docker Compose service definition                   |
| `redis.conf`       | Redis server configuration (ACL, persistence, etc.)  |
| `users.acl`        | Generated by `setup.sh` — do not edit manually       |
| `users.acl.example`| Example ACL file for reference                        |
| `setup.sh`         | One-shot setup: generates ACL + starts container      |

## Useful Commands

```bash
# Stop the container
docker compose down

# View logs
docker compose logs -f

# Connect via redis-cli
redis-cli -u "redis://<username>:<password>@localhost:6379"

# Restart after .env changes
./setup.sh
```
